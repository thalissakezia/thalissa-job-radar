# Fontes e referências

Esta primeira versão não incorpora nem redistribui o código dos projetos abaixo.
Eles foram usados como referência técnica para entender fontes e estratégias de coleta.

- FreeHire — https://github.com/strelov1/freehire — MIT. O radar usa a API pública documentada do projeto.
- JobSpy — https://github.com/speedyapply/JobSpy — MIT. Referência para uma futura integração com LinkedIn/Indeed.
- scraper-vagas-gupy — https://github.com/Henriquegp1/scraper-vagas-gupy — MIT. Referência para o endpoint usado pelo portal de empregabilidade da Gupy.

A integração Gupy usa um endpoint não documentado oficialmente e pode quebrar se a plataforma alterar o contrato.
